# PlacementPro AI Platform

## Overview

PlacementPro AI Platform is a full-stack web application that helps students prepare for placements by providing study materials, quizzes, company-specific preparation, and AI-powered guidance.

---

## Features

- User Authentication
- Admin Dashboard
- Placement Materials
- Online Quizzes
- Progress Tracking
- AI Career Assistant
- Company-wise Preparation

---

## Tech Stack

### Backend

- Java
- Spring Boot
- Spring Data JPA
- Spring Security
- MySQL

### Frontend

- React
- JavaScript
- Vite

- CSS
